# Reflection

This project helped me understand how Business Intelligence development can be combined with version control and collaborative development practices. Using Git and GitHub, I learned how to maintain a structured history of changes instead of treating the Power BI report as a single final file. Creating separate commits for the data model, DAX measures, and dashboard also made the development process easier to track.

In Power BI, I learned how to transform a flat sales dataset into a star-schema model using a fact table and dimension tables. Creating relationships between Fact_Sales, Dim_Date, Dim_City, and Dim_Product helped me understand how data modelling affects report analysis and filtering.

Working with DAX improved my understanding of measures such as Total Sales, Month-over-Month Growth, Running Total, City Sales Rank, and Average Transaction Value. I also learned that DAX suggestions need to be checked and corrected based on the actual business requirement and data model.

GitHub Copilot was useful for generating initial DAX suggestions and speeding up development. However, the suggestions were not always directly suitable, so I had to review the generated formulas and make corrections. Overall, the project gave me practical experience combining Power BI, DAX, Git, GitHub, and Copilot into a version-controlled BI workflow.
